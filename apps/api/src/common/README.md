# Common Module

Shared utilities, decorators, pipes, and constants.

## Contains:
- **decorators/**: Custom decorators (@IsOwner, @Roles, etc.)
- **pipes/**: Validation pipes (ParseIntPipe, ValidationPipe, etc.)
- **utils/**: Helper functions (formatters, validators, etc.)
- **constants/**: Application constants (error codes, messages, etc.)

## Principles:
- ✔️ No business logic
- ✔️ Reusable across modules
- ✔️ Pure functions and utilities
